# 스킬투머니

`guide/`의 설치 전 문서 → 설치 후 문서 순서로 만든 원데이 강좌 플랫폼과 파이썬 실습 자료입니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

<http://localhost:3000>에서 강좌 목록을 엽니다. PowerShell 실행 정책을 바꾸지 않도록 Windows 명령에는 `.cmd`를 사용했습니다.

실습실은 인터넷으로 Pyodide 0.27.7을 불러옵니다. 첫 준비에 시간이 필요합니다. 각 실행은 새 파이썬 변수 공간을 사용하며 오류가 나면 미리보기를 보존합니다. 무한 반복은 10초 뒤 중지하며 [처음 코드로]로 다시 준비할 수 있습니다. 6장 실습실 표는 연습용이며 실제 시트와 연결되지 않습니다.

`skilltomoney/`와 `public/`의 실습 자료는 같은 사본입니다. 실습 파일을 바꾸면 양쪽을 함께 수정하세요. 설치 전 소개 페이지는 38,000원과 할인 규칙을 사용하고, Next.js 강좌 카탈로그는 설치 후 문서에 따라 AI 자동화 35,000원을 사용합니다.

## 구글 시트 연결: 6장 22~29번

1. 기존 **스킬투머니 예약** 문서를 엽니다. 탭 **예약**의 A1:G1이 `날짜 | 강좌 | 이름 | 연락처 | 인원 | 결제 금액 | 신청 시각`인지 확인합니다. 기존 데이터는 지우지 않습니다.
2. [확장 프로그램] → [Apps Script]에서 기존 코드를 먼저 백업한 뒤 `apps-script/Code.gs`를 반영합니다.
3. [배포] → [새 배포] → [웹 앱]. 실행 계정은 **나**, 액세스 권한은 **모든 사용자**로 설정합니다. 권한 화면은 계정 소유자가 내용을 확인해 승인해야 합니다. 기존 웹 앱이 있다면 [배포 관리] → 연필 → **새 버전**으로 업데이트합니다.
4. `/exec`로 끝나는 웹 앱 URL을 `.env`의 `SHEET_URL=` 뒤에 넣고 개발 서버를 다시 실행합니다. `NEXT_PUBLIC_` 접두사는 붙이지 않습니다.
5. AI 자동화는 문서의 초기 설정상 마감입니다. 숏폼 편집 등 예약 가능한 강좌를 선택합니다. 빈 이름·좌석 초과는 저장되지 않아야 합니다. 정상 접수 시 완료 문구와 실제 시트의 새 행을 확인합니다. 테스트 예약도 좌석을 차지하므로 실제 운영 명단에 혼동되지 않게 관리하세요.

금액과 강좌 날짜는 화면이 보낸 값을 신뢰하지 않고 서버에서 계산합니다. Apps Script도 금액을 확인하고 잠금 안에서 기존 예약을 합산해 좌석 초과를 막습니다. `Code.gs`의 강좌 초기값은 `data/courses.js`와 맞춰야 합니다. `booked`는 수업 예제의 시작 예약 수이며 새 시트 행에 이미 포함된 인원을 중복으로 넣으면 안 됩니다. 기존 시트에 날짜가 날짜 형식으로 저장된 경우와 텍스트인 경우 모두 확인하세요.

웹 화면은 페이지를 열 때와 예약 완료 후 시트의 예약 인원을 조회하여 초기 예약 수(`booked`)에 합산합니다. 서버 환경의 `SHEET_KEY`에는 Apps Script의 `READ_KEY`와 같은 값을 설정하세요. 키는 브라우저에 전달되지 않습니다. 조회 실패 시 마지막 좌석 값과 안내를 표시하며, 실제 잔여 좌석은 신청 시 Apps Script에서 최종 검사합니다. 초기 예약 수에 시트의 인원을 중복으로 포함하지 마세요. 강사 모집은 안내만 표시하며 실제 접수·결제 기능은 없습니다.

## 장부 조회: 6장 38~40번

1. Apps Script [프로젝트 설정] → [스크립트 속성]에 **READ_KEY**와 긴 임의 값을 추가합니다. 코드나 Git에 키를 넣지 않습니다.
2. [배포 관리]에서 새 버전으로 업데이트합니다.
3. 코랩 왼쪽 열쇠(보안 비밀)에 **SHEET_URL**(웹 앱 URL), **SHEET_KEY**(READ_KEY와 같은 값)를 저장하고 해당 노트북의 액세스를 켭니다.
4. `python/ch06_read_sheet.ipynb`를 코랩 [파일] → [노트북 업로드]로 열어 실행합니다.

키가 틀리면 `{"error":"key"}`만 반환합니다. 조회 결과는 `date, course, people, total`만 포함하며 이름·연락처는 반환하지 않습니다. 읽기 키가 포함된 URL은 공유하지 마세요.

## GitHub: 6장 34~36번

기존 `skilltomoney-app` 비공개 저장소 주소를 확인하고, 로그인된 계정의 저장소인지 확인한 뒤 연결합니다. 주소를 추측하거나 기존 원격 기록을 강제로 덮어쓰지 않습니다.

```powershell
# 이 폴더에서 변경 기록 시작
git init -b main
# 환경 파일이 제외되는지 확인
git check-ignore .env
# 변경 파일 준비 및 첫 기록 저장
git add .
git commit -m "Build SkillToMoney course platform and Python lessons"
# 실제 저장소 주소로 연결한 뒤 원격 내용부터 확인
git remote add origin https://github.com/OWNER/skilltomoney-app.git
git ls-remote origin
# 빈 원격 저장소일 때 업로드
git push -u origin main
# 결과가 비어 있어야 함 (.env.example은 별도로 추적 가능)
git ls-files -- .env
```

Git 사용자 정보는 이 컴퓨터에 기존 설정이 있어 전역 설정을 변경하지 않았습니다. 원격에 기존 커밋이 있으면 먼저 내용을 확인해 별도 브랜치로 연결해야 합니다.
