[9] [파이썬 코드 (코랩)] 우리 앱을 파이썬으로  강좌 카드 목록 만들기
  ※ 코랩에서 실행
────────────────────────────────────────────────────────────
names = ["AI 자동화", "숏폼 편집", "엑셀 실무"]
prices = [35000, 45000, 30000]
seats = [8, 6, 10]
booked = [8, 2, 7]
for i in range(0, 3, 1):
    left = seats[i] - booked[i]
    if left == 0:
        state = "[마감]"
    elif left <= 2:
        state = "[마감 임박]"
    else:
        state = ""
    print(names[i], prices[i], "원 / 남은 자리", left, "석", state)

〈화면 출력〉
AI 자동화 35000 원 / 남은 자리 0 석 [마감]
숏폼 편집 45000 원 / 남은 자리 4 석
엑셀 실무 30000 원 / 남은 자리 3 석

[10] [프롬프트] 실습실 만들기 (lab04.html)
  ※ skilltomoney-app 열고 npm run dev 실행 중 / 새 대화 → 브라우저로 localhost:3000/lab04.html
────────────────────────────────────────────────────────────
skilltomoney-app/public 폴더에, skilltomoney 폴더의 2장에서 만든 lab.html을 복사해서 lab04.html을 만들어 줘. 파이썬 실행, 오류 안내, [처음 코드로], [⬇ 코랩 노트북으로 받기] 기능은 그대로 두고, 노트북 파일 이름만 ch04_lab.ipynb로 바꿔 줘.
- 맨 위 제목 띠는 "스킬투머니 실습실 · 4장"으로 바꿔 줘.
- 왼쪽 웹앱 화면: "원데이 강좌 목록"이라는 제목, [목록 새로 고침] 버튼, 그 아래 카드가 쌓이는 자리를 둬.
- input( ): 이번 코드는 input( )을 쓰지 않아.
- print( ): print( ) 한 줄을 강좌 카드 한 장으로 보여 줘. 줄의 맨 앞 강좌 이름은 굵게, "[마감]"은 회색 "마감" 표시로, "[마감 임박]"은 빨간 글씨로 바꿔 줘. 페이지를 열면 코드를 한 번 실행해 카드를 그려 줘.
- 오른쪽 코드 칸의 처음 코드는 아래 코드로 바꿔 줘.
names = ["AI 자동화", "숏폼 편집", "엑셀 실무"]
prices = [35000, 45000, 30000]
seats = [8, 6, 10]
booked = [8, 2, 7]
for i in range(0, 3, 1):
    left = seats[i] - booked[i]
    if left == 0:
        state = "[마감]"
    elif left <= 2:
        state = "[마감 임박]"
    else:
        state = ""
    print(names[i], prices[i], "원 / 남은 자리", left, "석", state)

  ✔ 확인: 페이지를 열면 카드 세 장이 그려지는가? AI 자동화 카드에 "마감" 표시가 붙는가?

[11] [실습실] 실습실에서 코드 고쳐 보기
  ※ 실습실 오른쪽 코드를 고치고 [▶ 웹앱에 적용하기]
────────────────────────────────────────────────────────────
① elif left <= 2를 elif left <= 3으로 고치고 적용한다. 남은 자리가 3석인 엑셀 실무 카드에 "마감 임박"이 나타난다.
② booked를 [8, 5, 7]로 바꾸면 숏폼 편집 카드는 어떻게 바뀌는가? 남은 자리 1석, 마감 임박이 된다.
③ 네 번째 강좌 "스마트스토어"(40000원, 정원 6, 예약 5)를 네 리스트에 하나씩 추가하고 적용해 보자. 카드가 늘지 않는다면 range(0, 3, 1)의 끝값을 4로 고친다. 강좌 수가 바뀔 때마다 끝값을 고쳐야 하는 불편함은 5장에서 len( )으로 해결한다.
④ 고친 코드를 [⬇ 코랩 노트북(.ipynb)으로 받기]로 내려받아 코랩에서 [파일] → [노트북 업로드]로 열고 실행해 본다. 실습실과 같은 결과가 나와야 한다.

[17] [파이썬 코드 (코랩)] 우리 앱을 파이썬으로  강좌 카탈로그와 "예약 가능한 강좌만 보기"
  ※ 코랩에서 실행
────────────────────────────────────────────────────────────
courses = [
    {"id": 1, "name": "AI 자동화", "price": 35000, "seat": 8, "booked": 8, "tags": ["초보 환영", "2시간"]},
    {"id": 2, "name": "숏폼 편집", "price": 45000, "seat": 6, "booked": 2, "tags": ["캡컷", "3시간"]},
    {"id": 3, "name": "엑셀 실무", "price": 30000, "seat": 10, "booked": 7, "tags": ["함수 실습"]},
    {"id": 4, "name": "스마트스토어", "price": 40000, "seat": 6, "booked": 5, "tags": ["상세페이지", "창업 준비"]}
]
only_open = True
for i in range(0, len(courses), 1):
    c = courses[i]
    left = c["seat"] - c["booked"]
    if only_open and left == 0:
        continue
    print(c["name"], c["price"], "원 / 남은 자리", left, "석", c["tags"])

〈화면 출력〉
숏폼 편집 45000 원 / 남은 자리 4 석 ['캡컷', '3시간']
엑셀 실무 30000 원 / 남은 자리 3 석 ['함수 실습']
스마트스토어 40000 원 / 남은 자리 1 석 ['상세페이지', '창업 준비']

[30] [파이썬 코드 (코랩)] 우리 앱을 파이썬으로  예약 신청 → JSON → 시트의 한 행
  ※ 코랩에서 실행
────────────────────────────────────────────────────────────
import json
prices = {"AI 자동화": 35000, "숏폼 편집": 45000, "엑셀 실무": 30000}
rsv = {"date": "2026-11-07", "course": "AI 자동화", "name": input("이름: "), "phone": "010-1111-2222", "people": int(input("인원: "))}
rsv["total"] = prices[rsv["course"]] * rsv["people"]
text = json.dumps(rsv, ensure_ascii=False)
print("보내는 JSON:", text)

data = json.loads(text)
keys = ["date", "course", "name", "phone", "people", "total"]
row = []
for i in range(0, len(keys), 1):
    row.append(data[keys[i]])
print("시트에 추가되는 행:", row)

[37] [프롬프트] 파이썬 자동화 미션  예약 데이터 백업과 복원
  ※ skilltomoney-app이 아닌 다른 폴더 / 새 대화 → 코드는 코랩 새 셀에 붙여 넣고 실행
────────────────────────────────────────────────────────────
예약 데이터를 JSON으로 백업하고 복원하는 파이썬 프로그램을 만들어 줘.
- 시트의 행은 [날짜, 강좌, 이름, 인원] 리스트이고, 여러 행을 담은 2차원 리스트가 있어.
- 각 행을 date, course, name, people 키를 가진 딕셔너리로 바꿔서 리스트에 모은 다음, json.dumps로 백업 글자를 만들어 줘. 한글이 그대로 보이게 해 줘.
- 그 글자를 json.loads로 되돌려서 두 번째 예약의 이름과 인원을 출력해 줘.
- for 문은 range(시작, 끝, 증가)로 써 줘.

[38] [프롬프트] 연결 미션 06  장부 읽기 주소 만들기 (doGet)
  ※ 새 대화 → 받은 코드를 Apps Script에 추가
────────────────────────────────────────────────────────────
구글 시트 Apps Script에 doGet 함수를 추가하는 코드를 만들어 줘.
- 웹 앱 URL 뒤에 ?key=값 을 붙여 GET 요청을 보내면 "예약" 시트의 모든 행을 JSON 목록으로 돌려줘.
- 각 행은 {"date", "course", "people", "total"} 키만 담아 줘. 이름과 연락처는 절대 보내지 마.
- key 값은 코드에 직접 쓰지 말고 Apps Script의 스크립트 속성에 READ_KEY라는 이름으로 저장해서 비교해 줘. 키가 다르면 {"error": "key"}만 돌려줘.
- 스크립트 속성을 저장하는 방법과 새 버전으로 다시 배포하는 방법도 알려 줘.

[39] [직접 하기] 스크립트 속성과 코랩 보안 비밀
  ※ Apps Script와 코랩에서 직접
────────────────────────────────────────────────────────────
Apps Script → 스크립트 속성에 READ_KEY(영문·숫자 섞은 긴 글자) 저장
[배포] → [배포 관리] → 새 버전으로 다시 배포
코랩 왼쪽 열쇠 아이콘(보안 비밀) → SHEET_URL(웹 앱 URL), SHEET_KEY(READ_KEY와 같은 값) 저장 → 노트북 액세스 켜기

────────────────────────────────────────────────────────────
[40] [파이썬 코드 (코랩)] 파이썬으로 장부 읽기
  ※ 코랩 새 셀에 붙여 넣고 실행
────────────────────────────────────────────────────────────
import json
import urllib.request
from google.colab import userdata

url = userdata.get("SHEET_URL") + "?key=" + userdata.get("SHEET_KEY")   # ①
text = urllib.request.urlopen(url).read().decode("utf-8")              # ②
rows = json.loads(text)                                                # ③
print("장부에서 예약", len(rows), "건을 읽었습니다.")

people = {}
for i in range(0, len(rows), 1):                                       # ④
    course = rows[i]["course"]
    if course in people:
        people[course] = people[course] + rows[i]["people"]
    else:
        people[course] = rows[i]["people"]
print("강좌별 예약 인원:", people)
print("백업:", json.dumps(rows, ensure_ascii=False))
